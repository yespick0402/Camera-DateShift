STEP 04 · 개인 설정

키보드 단축키

변경할 항목의 단축키 버튼을 누르고 원하는 키 조합을 누르세요.

파일 확인 탭⌘1 / Ctrl+1
날짜 변경 탭⌘2 / Ctrl+2
저장 및 결과 탭⌘3 / Ctrl+3
단축키 탭⌘4 / Ctrl+4
파일 선택사진·영상 파일 불러오기
폴더 선택폴더와 하위 폴더 분석
다음 탭오른쪽 작업 단계로 이동
이전 탭왼쪽 작업 단계로 이동
날짜 변경 실행저장 탭에서 선택 파일 변경
파일명 검색파일 확인 탭의 검색창으로 이동
큰 미리보기 열기/닫기Space 기본값 · 사진/영상 확인
파일 체크 / 체크 해제날짜 변경 탭에서 활성 파일 선택
다음 파일→ 또는 ↓ 방향으로 이동
이전 파일← 또는 ↑ 방향으로 이동

탭 이동 기본값: ⌘1~⌘4 (Windows: Ctrl+1~4). Mac은 ⌘, Windows는 Ctrl을 사용합니다. 단축키는 이 프로그램 창이 활성화된 동안에만 작동합니다.

단축키는 이 컴퓨터에 저장되며, 앱을 다시 열어도 유지됩니다.
